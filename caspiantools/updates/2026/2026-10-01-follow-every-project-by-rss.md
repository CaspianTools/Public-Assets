Every project on caspiantools.com now has an RSS feed of its updates and release notes. Subscribe to one product at caspiantools.com/feeds/<project>.xml, or to the whole studio at caspiantools.com/feed.xml. A JSON Feed version is also available.

Each project page also shows its latest updates, including products whose source code is private. Most feed readers find the feed automatically from the project page's address.

All updates now live in one public place, github.com/CaspianTools/Public-Assets, so nothing gets lost in private repositories.
