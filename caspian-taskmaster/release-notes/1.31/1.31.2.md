# Caspian Taskmaster 1.31.2: Screenshots are back on the Marketplace, and the download is smaller

The Marketplace page for Caspian Taskmaster now shows every screenshot, and the download is a lot smaller.

- 🖼️ All 10 screenshots show up again: Kanban, table, metrics, sprints, AI panel and more
- 📦 The extension package dropped from 3.3 MB to 670 KB

https://marketplace.visualstudio.com/items?itemName=CaspianTools.caspian-taskmaster

## Full changes

### Fixed
- **Screenshots now show up on the Marketplace and in VS Code's extension page.** The README linked them by relative path, which `vsce` turns into a `github.com/CaspianTools/caspian-taskmaster/raw/...` URL. The repo is private, so every image returned 404. The screenshots are now hosted in the public `CaspianTools/Public-Assets` repo and linked by absolute URL.

### Changed
- `media/screenshots/` is no longer shipped in the VSIX (about 1.7 MB smaller). The extension never loaded those files.
