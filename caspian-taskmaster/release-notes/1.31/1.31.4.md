# Caspian Taskmaster 1.31.4: Sync tells you when it needs a reconnect

caspiantools.com now ties each VS Code pairing to one workspace and lets it run for 180 days. When a pairing expires, the extension says so once and offers a Reconnect button, instead of failing quietly in the log every 15 seconds.

- 🔔 One notification, one button: **Reconnect** reopens the pairing flow
- 🔒 A pairing opens only the workspace you picked, and only your tasks and notes there
- 🕒 Pairings made before today keep working until 1 February 2027

## Full changes

### Changed
- **Sync stops and asks you to reconnect when caspiantools.com refuses the pairing, instead of retrying forever.** caspiantools.com now scopes the VS Code pairing token to the workspace you picked and expires it 180 days after pairing (pairings made before this change keep working until 2027-02-01, then need a reconnect too). Before, an expired or out-of-scope pairing made both sync loops fail every 15 seconds in the log with no visible sign. Now two consecutive `PERMISSION_DENIED` results stop the engine, set the last error to a plain explanation, and show one notification with a **Reconnect** button that runs *Connect to caspiantools.com*.
- **Share to the web is now owner-only on the server.** Making a task public is accepted by caspiantools.com only from the workspace owner; a member's Share reports `PERMISSION_DENIED`.
