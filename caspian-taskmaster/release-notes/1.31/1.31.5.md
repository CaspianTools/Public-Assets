# Caspian Taskmaster 1.31.5: Same release as 1.31.4, with an icon the Marketplace accepts

1.31.4 could not be uploaded to the VS Code Marketplace because the extension icon was larger than the 1024-pixel limit. 1.31.5 is the same build with a 512-pixel icon.

- 🔔 Sync stops and offers **Reconnect** when caspiantools.com refuses the pairing (from 1.31.4)
- 🖼️ Icon resized so the store accepts the upload

Your issue tracker belongs where your code lives.

https://marketplace.visualstudio.com/items?itemName=CaspianTools.caspian-taskmaster

---

## Full changes

### Fixed
- **Marketplace upload was refused: "The provided icon image exceeds the maximum allowed dimensions of 1024 by 1024 pixels."** `media/icon.png` had been 1363×1221 since the 1.31.3 artwork refresh. It is now 512×512 (the same artwork, fitted on a transparent square), which is also the size VS Code renders it at. No functional change from 1.31.4; this release exists so the 1.31.4 changes can actually be published.
