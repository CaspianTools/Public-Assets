Caspian Taskmaster 0.14 just dropped — setting up AI features is now effortless.

- Run **Detect AI Provider** from the Command Palette — it scans for every installed AI extension and language model
- Works with Copilot, Claude, Gemini, Cody, Continue, Amazon Q, and any extension that registers a VS Code language model
- Pick a model from the list and you're done — no manual endpoint or key configuration needed for VS Code LM-based providers
- On first launch, the extension automatically detects available models and prompts you to configure

No more guessing which setting to pick.
