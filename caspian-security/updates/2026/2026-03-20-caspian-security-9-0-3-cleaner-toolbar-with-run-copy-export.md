The Results panel toolbar just got a serious upgrade.

- ▶️ **Run** dropdown — launch any scan directly from the panel: Security Check, Current File, Entire Workspace, or Uncommitted Files
- 📋 **Copy** dropdown — Copy All, or filter by severity: Errors, Warnings, or Info only
- ⬇️ **Export** dropdown — CSV, JSON, and SARIF (GitHub) all under one button

Fewer buttons, more power. Every action is one click away.
