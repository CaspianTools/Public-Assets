Caspian Security 10.13.0 is out. The Security Tasks checklist was stuck in the narrow sidebar, where half of every task title got cut off — now it opens in the main editor window.

- 🖥️ New **Open in Editor** button in the Security Tasks title bar — one click, full-width tab
- 📖 Nothing truncated: task titles and due dates wrap instead of trailing off into an ellipsis
- 🔄 Sidebar and editor tab stay in sync — complete a task in one, it updates in the other
- ⌨️ Also reachable from the Command Palette, the Results panel, and the overdue-task notification

23 recurring security tasks — dependency audits, secret rotation, git-history scans — now readable at a glance.
