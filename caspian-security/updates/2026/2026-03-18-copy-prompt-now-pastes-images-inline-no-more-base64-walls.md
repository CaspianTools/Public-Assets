Caspian Taskmaster 0.17.5 makes Copy Prompt much more useful when your issues have screenshots.

- 🖼️ Copy Prompt now writes both text and HTML to the clipboard
- When pasting into rich text apps (Slack, email, AI tools, Google Docs), images appear inline
- Falls back to text-only if the rich clipboard API is unavailable
- Also includes the image paste fix from 0.17.4
