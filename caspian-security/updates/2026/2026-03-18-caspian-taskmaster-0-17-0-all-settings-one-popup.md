Caspian Taskmaster v0.17.0 consolidates all configuration into one place.

- ⚙️ **Settings tab** — GitHub token with live verification, sync interval, MCP port, and more — with User/Workspace scope toggle
- 🤖 **AI tab** — pick your provider (VS Code LM, OpenAI-compatible, Claude), set endpoint, API key, and model
- 🚀 **No more Welcome screen** — new installs go straight to the tracker with Settings auto-opened
- 🧹 Onboarding panel removed — all config lives in the Settings popup now
