Caspian Taskmaster 0.7.2 fixes a sync gap that could leave issues stuck in the wrong status.

- Closing an issue on GitHub now correctly marks it as Done in the extension
- No more "Ongoing" badges on issues you already closed
- Works even without a status: label — the extension reads GitHub state directly
