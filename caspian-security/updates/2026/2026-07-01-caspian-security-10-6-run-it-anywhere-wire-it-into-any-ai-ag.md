Caspian Security 10.6 is here — the scanner now runs **anywhere**, not just in VS Code.

- 🖥️ New unified `caspian` command for PowerShell, cmd & bash — `npx -y caspian-security caspian scan .` or `npm i -g caspian-security`
- 🤖 One line in your CLAUDE.md / Cursor / Antigravity rules lets any AI agent run Caspian mid-task — `caspian snippet` writes it for you
- 🔌 MCP config for Claude Code, Cursor, Antigravity, Claude Desktop & Cline — `caspian mcp-config --client <name>`
- 🔒 Zero setup in your repos — Caspian only emits text you choose to paste; it never writes into a project you don't own
