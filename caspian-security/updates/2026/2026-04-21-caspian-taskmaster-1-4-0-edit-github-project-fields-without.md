Phase 3 is here. The Projects tab on every issue is now fully interactive.

✏️ New in 1.4.0:
- Add the current issue to any enabled project via an inline dropdown
- Remove from a project with one click
- Edit Status, Priority, Iteration, and every custom field (text, number, date, single-select, iteration) inline
- Writes go to GitHub immediately — no manual sync needed

Plus a Phase 2 cleanup: failed project fetches no longer risk dropping legitimate links.
