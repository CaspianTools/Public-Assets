Setting up GitHub sync just got a lot smoother.

- **Live token verification** — type your PAT and see `✓ your-login` or `✗ Invalid` inline, instantly
- **Repository dropdown** — your accessible repos load automatically once the token is verified; pick from a list instead of typing the name
- **Token masking** — the PAT is now masked in the VS Code Settings UI and stored in the system secret store
- **Smarter `configureRepo` command** — verifies the token before moving on; repo step shows a searchable QuickPick of your repos
