Caspian Taskmaster 1.10 is out. Every row and every Kanban card now tells you, at a glance, how connected and how discussed an issue is.

- 🔗 **Dependency count** as a dedicated, sortable column in the Table view and inline on every Board card
- 💬 **Comment count** synced from GitHub on every row and card
- Zero counts are dimmed and number-less so heavily-trafficked issues actually stand out
- No extra API calls — comment count piggybacks on the existing GitHub sync

No more clicking into the modal just to see how busy an issue is.
