Phase 2 is live. Enable a GitHub Project and its field values come with you into the issue editor.

📋 New in 1.3.0:
- Every sync pulls project items for each enabled project
- Each issue shows a Projects tab listing every project it belongs to
- Field values (Status, Priority, Iteration, custom fields) pulled alongside
- Stale links automatically pruned when an item is removed from a project on GitHub

Read-only for now — editing fields and add/remove lands in Phase 3.
