Caspian Taskmaster 0.2.0 is the biggest update yet — 12 new developer-native features built straight into VS Code.

- **Kanban board** with drag-and-drop — switch from table to board view in one click; drag cards to change status
- **AI triage** — as you type a new issue, priority/type/category suggestions appear based on what you write and your existing issues
- **Metrics dashboard** — open a full panel with open/closed counts, priority breakdown, status donut, 12-week trend, and avg days to close
- **Conflict resolution** — when GitHub and local edits collide, pick field-by-field which version to keep
- **Commit integration** — `closes mod1180` in a commit message auto-closes the issue
- **TODO Harvester** — scan your workspace for TODO/FIXME/HACK/BUG comments and turn them into tracked issues in one click
- **Code references** — attach file/line positions to issues; gutter icons appear in the editor at linked lines
- **Issue dependencies** — blocks/blockedBy relationships with cycle detection
- **Rich markdown editor** — live split-pane preview in the create/edit modal
- **Milestones** — create sprints, assign issues, group the board
- **Bulk operations** — select multiple issues, change status/priority/delete in one action
- **Saved views** — name and save any filter+sort combination
