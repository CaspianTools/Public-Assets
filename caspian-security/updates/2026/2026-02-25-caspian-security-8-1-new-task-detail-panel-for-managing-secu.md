Caspian Security 8.1 is here — security tasks now open in a dedicated detail panel with full context and one-click actions.

- View task metadata at a glance: status, priority, interval, category, due dates, and related rules
- Mark complete, snooze, change interval, dismiss, or reinstate — all from the panel
- Snooze options: 1 hour, 4 hours, 1 day, 3 days, or 1 week
- Auto-refreshes when task state changes
