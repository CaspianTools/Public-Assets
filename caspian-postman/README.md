# caspian-postman

Public updates for SendHaste (formerly Caspian Mail). Each update is one Markdown file under `updates/<YYYY>/`. Start a new one from [`_templates/update.md`](../_templates/update.md).

caspiantools.com shows them on the project page and in the RSS / JSON feeds. See the [root README](../README.md#feeds) for the feed URLs. Never rename a published file, because its path is its ID in the feeds.
