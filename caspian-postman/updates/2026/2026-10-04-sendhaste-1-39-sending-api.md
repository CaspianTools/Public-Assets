Your apps, websites and scripts can now send email from your own addresses with one HTTPS request: order confirmations, password resets, contact forms and reports. An administrator makes an API key in Settings → API keys and can limit it to one address; a key can be revoked at any time. Emails sent this way go out like the ones you write in SendHaste, with the same daily limits. The full guide, with examples and every field and error, is at https://sendhaste.com/en/help/api. The website also has a new Support column in its footer, with the Help center and a way to contact us.
