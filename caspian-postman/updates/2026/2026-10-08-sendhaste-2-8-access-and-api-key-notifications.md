The bell now tells you when you're taken off a domain, when you lose access to a mailbox (it names which ones), and when a mailbox you had is removed. Org Super Admins also get a heads-up when someone makes or revokes an API key, under a new **Security** group. Each has its own switch in **Settings** → **Notifications**. More in the help center: https://sendhaste.com/en/help/notifications
