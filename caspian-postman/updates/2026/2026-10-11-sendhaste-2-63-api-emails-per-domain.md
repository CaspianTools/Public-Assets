The emails your websites send by name can now be connected for every address on your domains, for one domain, or for one address. Pick it under Sent from, in Settings → API keys → Emails your websites send. An API key made for one domain or one address sees and sends only the emails meant for its own addresses, so websites on different domains no longer see each other's. The same name can be connected at each level, and the most specific one is sent. Emails connected before stay available to every address until you choose otherwise. Details are in Help, under Sending API: https://sendhaste.com/en/help/api
