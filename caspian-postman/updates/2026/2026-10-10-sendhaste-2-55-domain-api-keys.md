You can now make an API key that sends only from one of your domains, which is handy for automated emails like order confirmations, alerts and reports. In Settings → **API keys**, under **Sends from**, pick **Any address on** your domain: the key can send from any address on that domain, such as noreply@ or orders@, and from no other. Each domain's page in Settings → **Domains** also has a **Make an API key for** button that picks the domain for you. Only the sender is limited: the emails can still go to anyone, at your company or outside it. More: https://sendhaste.com/en/help/api
