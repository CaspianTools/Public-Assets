Chose **Adult** when setting up Zekio? Your profile just got a little cleaner.

We noticed that the settings screen was still showing a **Class** field for adult users — even though a class only really makes sense for students. That's now fixed: if you signed up as an adult, the Class row simply won't appear. And if you're a student, nothing changes — you'll still see and be able to update your class whenever you like.

Small touch, but it keeps your profile showing only what's relevant to you. Enjoy! ✨
