# caspian-notes

Public updates for Caspian Notes. Each update is one Markdown file under `updates/<YYYY>/`. Start a new one from [`_templates/update.md`](../_templates/update.md). Versioned releases can instead go in `release-notes/<major>.<minor>/<X.Y.Z>.md`, from [`_templates/release-note.md`](../_templates/release-note.md).

caspiantools.com shows them on the project page and in the RSS / JSON feeds. See the [root README](../README.md#feeds) for the feed URLs. Never rename a published file, because its path is its ID in the feeds.
