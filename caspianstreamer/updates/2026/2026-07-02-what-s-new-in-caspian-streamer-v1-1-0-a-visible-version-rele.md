## What's new in Caspian Streamer v1.1.0 🎉

You can now **see exactly which version you're running** — and know what changed in each update at a glance.

### What you'll notice

- **A version badge on the logo.** A small `v1.1.0` now sits right next to the Caspian Streamer name in the top bar, so you always know which build you're on. The same version appears on the **About** and **Changelog** pages.
- **A "What's New" note on the Updates page.** Every release now carries a one-line summary of what changed. Open **Updates** and you'll see it front and centre — whether you're already up to date or a newer build is ready to install.
- **A tidier changelog.** Each entry is now labelled with its version and date, so it's easy to trace when a feature landed.

### Why it matters

When you spot something new (or want to tell us about something), you can point to an exact version — and when we ship an update, the app tells you what's in it without you hunting through notes. Little touches that make the tool easier to trust and follow.

As always, Caspian Streamer runs entirely in your browser — private, free, and yours. Thanks for creating with us! 🎬
