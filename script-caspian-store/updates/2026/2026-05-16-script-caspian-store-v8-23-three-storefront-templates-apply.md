A fresh install previously dropped owners into an empty storefront. v8.23 ships **three complete templates** — fashion, electronics, home goods — each with theme + ~9 products + 3 categories + four content pages + 2 journal articles + curated Unsplash imagery. One click in the new `/admin/templates` page (or the setup wizard) seeds the entire site.

- 🛍️ **Fashion Minimal** — clean white palette, editorial photography, apparel + accessories
- 🎧 **Electronics Tech** — dark mode with green accent, audio + wearables + desk gear
- 🏡 **Home Goods** — warm earth tones, lifestyle interior photography, kitchen + living + workspace
- 🔁 **Merge / Replace modes** — re-apply safely, or wipe-and-reseed for a fresh start

Setup wizard owners pick a template (or "Start blank") between Site Info and Branding; the chosen theme + hero pre-populate the branding step.

Upgrade:

```bash
npm install github:CaspianTools/script-caspian-store#v8.23.0
```
