**script-caspian-store v9.6.0 is out** — the admin Products page now has a **Masonry view** alongside the classic table, so you can scan an image-led catalog visually instead of row by row.

- 🖼️ **Table | Masonry toggle** in the page header — Table stays the default, Masonry is one click away.
- 🧱 **True staggered grid** — CSS multi-column with natural-aspect images; 4 columns down to 1 as the screen narrows.
- 🎛️ **Nothing lost** — the same filters, status badges, and row actions (Edit / View / Delete) work in both views.
- ✅ **No consumer action required** — admin-only UI; existing installs pick it up on upgrade.

Upgrade: `npm install github:CaspianTools/script-caspian-store#v9.6.0`

Repo: https://github.com/CaspianTools/script-caspian-store
