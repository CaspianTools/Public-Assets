v9.14.0 makes the storefront currency picker work for every market: the Settings → Localization currency field is now the **complete ISO 4217 world-currency list** in a type-to-filter combo, not a 29-item dropdown.

- 🌍 Every world currency — search by name or ISO code
- 🔎 Same searchable combo already used by the Country picker
- 🎛️ Settings sidebar now renders its per-section icons
- 💱 Correct default decimals for zero- and three-decimal currencies (JPY, KWD, …)

Upgrade: `npm install github:CaspianTools/script-caspian-store#v9.14.0`
