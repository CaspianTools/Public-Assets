# Caspian Office 1.231.3: Plain-http addresses explained

Typing a plain http address into the Mobile view tester used to leave the frames quietly blank. The tool now tells you why and shows the way around it.

- **Fixed — No more silent blank frames for http addresses.** Browsers refuse to show an http page inside an https page, and only localhost is exempt. The stage now says so and points to the window button, which opens the address in a popup of the device's size.
- **Improved — Clearer guidance for dev servers.** The address field suggests localhost, and the FAQ explains when to use the window button, in all 12 languages.

Preview your work at real device widths, from localhost to a LAN server, all in your browser.

## Full changes

### Fixed
- **A plain-http address no longer leaves the frames silently blank.** Browsers refuse to show an http:// page inside an https page (mixed content), and only localhost is exempt, so a LAN dev server such as http://192.168.1.20:5173 never appeared in the Mobile view tester's frames. The stage now says so and points to the window button, which opens the address in a popup of the device's size and is not subject to that rule. The address placeholder suggests localhost, and the dev-server FAQ explains the difference in all 12 languages.
