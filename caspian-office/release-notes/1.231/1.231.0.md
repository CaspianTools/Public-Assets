# Caspian Office 1.231.0: Mobile view tester gets a sidebar and screenshots

The Mobile view tester has a new layout: every control lives in one settings column, the stage takes the full height of the page, and each device frame can be saved as a PNG screenshot.

- **New — Screenshot any device screen.** A camera button on every frame saves the screen as a PNG at the device's exact size, bezel and notch included. Shoot all saves one image per frame in a single zip.
- **Improved — One settings column.** Source, devices, custom size and view sit in a sidebar beside the stage. Devices are picked from grouped dropdowns for phones, tablets and laptops & desktops, with chips showing what is on stage.
- **Improved — Cleaner tool, fuller guide.** The notes about sites that refuse to be embedded moved into the tool's guide and FAQ, in all 12 languages.

Preview a page at real device widths and take the screenshots for your design review, all in your browser.

## Full changes

### Added
- **Save a screenshot of any device screen.** Every frame in the Mobile view tester now has a camera button that saves the screen as a PNG at the device's exact CSS size — bezel and notch included when the device frame is on — and **Shoot all** saves one image per frame in a single zip. Screenshots work for pasted HTML and HTML files; a page loaded by URL belongs to another site, which the browser keeps hidden from the page, so the camera says so instead of saving a blank image.

### Changed
- **All controls in one settings column.** The three stacked control cards are gone. Source, devices, custom size and view now sit in a sidebar beside the stage, which takes the full height of the pane. Devices are picked from three grouped dropdowns (phones, tablets, laptops & desktops) with the chosen ones listed as chips underneath, and the stage header reads the orientation, the frame count and the fit scale.
- **Explanations moved to the tool's guide.** The note about sites that refuse to be embedded (X-Frame-Options / CSP) and the QR card left the tool itself; the guide's "About this tool" and FAQ carry them now, in all 12 languages.
