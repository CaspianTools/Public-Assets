# Caspian Office 1.232.1: Five more tools translated inside

The last five tools whose screens were still in English now speak all 12 of Caspian Office's languages, and nine more help guides are translated to match.

- **Improved — Every tool now speaks your language inside.** Form builder, UI builder, TOP-SET evidence board, Tripod Beta and Screenshot are translated into Arabic, Azerbaijani, Chinese, French, German, Indonesian, Japanese, Portuguese, Russian, Spanish and Turkish.
- **Improved — Nine more help guides translated.** The guides for those five tools, plus PDF to Word, PDF to Excel, PDF to PowerPoint and the EXIF viewer, use the same button names as the tools themselves.

190 private, offline tools, now fully in your language.

🔗 Live: https://caspianoffice.io
📝 Changelog: https://caspianoffice.io/changelog

## Full changes

### Changed
- **Every tool now speaks your language inside.** The last five tools whose screens were still in English (the Form builder, UI builder, TOP-SET evidence board, Tripod Beta and Screenshot) are translated into all 11 other languages. Screenshot also gets its translated name and subtitle in the menu and search.
- **Nine more help guides translated.** The "About this tool" guide for those five tools, plus PDF to Word, PDF to Excel, PDF to PowerPoint and the EXIF viewer, now reads in all 12 languages, using the same button names as the tool itself.
