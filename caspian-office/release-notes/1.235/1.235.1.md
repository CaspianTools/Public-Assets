# Caspian Office 1.235.1: A tool installs as its own app, even next to the Workspace

If you had the Workspace installed, installing a single tool such as Sudoku gave you no separate app or icon. That is fixed on desktop and on phones.

- **Fixed — Single-tool installs.** Install app on a tool's page now adds that tool with its own name, icon and window, alongside the Workspace.
- **Improved — Older shortcuts keep working.** Single-tool shortcuts made before this release still open their tool as its own app.

Every tool as its own offline app, or all of them together in one.

🔗 Live: https://caspianoffice.io/tool/sudoku/
📝 Changelog: https://caspianoffice.io/changelog

---

## Full changes

### Fixed
- **Installing a single tool made no app or icon if the Workspace was already installed.** The Workspace claimed every address on the site, so the browser treated each tool as part of it and would not add the tool on its own, on desktop or on phones. The Workspace now covers only its own pages, and each tool's app lives at its own address outside them, so **Install app** on a tool's page adds that tool with its own name, icon and window.

### Changed
- **Older single-tool installs keep working.** Shortcuts made for one tool before this release still open that tool as its own app.
