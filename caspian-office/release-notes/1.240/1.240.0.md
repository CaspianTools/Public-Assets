# Caspian Office 1.240.0: An event menu, and nothing is added until you press Save

Click any event in the Calendar planner for a quick menu: edit, duplicate, copy it forward, recolour or delete it. A stray click on the calendar no longer leaves an empty event behind, because nothing is added until you press Save.

- **New — Event menu.** Edit, Duplicate, Copy to next day, Copy to next week, category colours and Delete, right where you click.
- **Fixed — No accidental events.** Cancel, ✕, Esc or a click outside throws a new event away and undoes unsaved changes.

Free, private and offline: your calendar never leaves your browser.

🔗 Live: https://caspianoffice.io/tool/calendar-planner/

## Full changes

### Added
- **Event menu.** In the Calendar planner, click an event (or right-click it) for a quick menu: **Edit**, **Duplicate**, **Copy to next day**, **Copy to next week**, a row of category colours and **Delete**, with **Delete this date only** for a repeating event. Double-click an event to open its editor straight away.

### Fixed
- **An accidental click no longer leaves an event behind.** Clicking the calendar opens the editor for a new event, but the event is only added when you press **Save** (or Enter in the title). Cancel, ✕, Esc or a click outside the editor throws it away, and the same buttons undo unsaved changes to an existing event.
