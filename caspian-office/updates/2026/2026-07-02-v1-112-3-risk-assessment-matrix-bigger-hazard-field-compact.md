**Shipped v1.112.3** · 2026-07-02

A small ergonomics pass on the **Risk Assessment Matrix** register: more room to describe each hazard, and tidier scoring dropdowns.

- **Improved** — The **Risk / hazard** column now takes the lion's share of each row, so a full hazard description fits without feeling cramped.
- **Improved** — The likelihood & severity dropdowns (**L**, **S**, **RL**, **RS**) are now compact **1–5** number pickers instead of "3 — Possible" text. The wording stays available on hover, and the colour-banded matrix + column tooltips still spell out every level.
