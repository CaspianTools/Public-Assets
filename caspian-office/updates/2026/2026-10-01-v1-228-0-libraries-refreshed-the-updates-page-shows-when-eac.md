**Shipped v1.228.0** · 2026-10-01

Seven bundled libraries are updated, and the Updates page now shows when each library's latest version was released.

- **New — release dates on the Updates page.** Under each library's latest version you can now see when it was published. In all 12 languages.
- **Improved — seven libraries updated:** pdf.js 6.3.289, Mediabunny 1.61.0 (with its MP3 encoder), DOMPurify 3.4.16, marked 18.0.14, JSZip 3.10.2, mammoth 1.13.0 and Transformers.js 4.3.0.
- **Fixed — the Updates page spots older libraries again.** Its list of latest versions had not been refreshed, so every library read "current". The list is now accurate. qrcode-generator is correctly shown as behind: version 2 changes its API, so that upgrade will be tested separately.
